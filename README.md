# 웅심옹심: 미라클 원투

강원FC 마스코트 **웅심이**(반달가슴곰)와 **옹심이**(말하는 감자)가 함께 뛰는 1인용 탑다운 픽셀 축구 아케이드입니다.
**비공식 팬게임**이며, 캐릭터 능력과 스테이지 이야기는 이 게임을 위해 만든 창작 설정입니다.

> 유인 → 패스 → 침투 → 리턴 패스 → 원투 피니시 → 관중 폭발!

## 실행 방법

- **가장 간단한 방법**: `index.html`을 더블클릭해 크롬이나 엣지에서 엽니다. 설치할 것은 없습니다.
- **로컬 서버로 실행** (권장, 모바일 기기에서 접속할 때):
  ```bash
  python -m http.server 8123
  ```
  이 폴더에서 실행한 뒤 `http://localhost:8123`에 접속합니다.
- 소리는 첫 키 입력이나 탭 이후에 켜집니다(브라우저 정책).

## 휴대폰에서 하기

**같은 Wi-Fi에서 바로 하기**
1. PC에서 이 폴더를 열고 `python -m http.server 8123`을 실행합니다. Windows 방화벽이 물으면 '개인 네트워크 허용'을 누릅니다.
2. 휴대폰 브라우저에서 `http://<PC의 내부 IP>:8123`에 접속합니다. PC의 내부 IP는 `ipconfig`로 확인할 수 있습니다(예: 192.168.x.x).
3. 휴대폰을 가로로 돌려 플레이합니다. 안드로이드는 타이틀의 **전체 화면 (가로)** 버튼을 쓸 수 있습니다.

**앱처럼 설치하기 (홈 화면 아이콘, 전체 화면, 오프라인)**
- 이 게임은 PWA입니다. 앱 설치와 오프라인 실행은 브라우저 정책상 **HTTPS 주소**에서만 켜집니다.
- 폴더 전체를 GitHub Pages, Netlify, Cloudflare Pages 같은 정적 호스팅에 올리면 HTTPS 주소가 생깁니다.
  - 안드로이드 크롬: 메뉴 → **앱 설치**(또는 홈 화면에 추가)
  - 아이폰 사파리: 공유 → **홈 화면에 추가**
- 설치한 뒤에는 인터넷 없이도 실행되고, 온라인일 때 새 버전을 자동으로 받습니다.

**모바일 조작**
- **이동**: 플레이 중 **왼쪽 화면 아무 곳이나** 누르면 그 자리에 이동 패드가 생깁니다.
- **패스·슛**: 오른쪽 버튼입니다. 슛 버튼을 길게 누르면 강슛이고, 차징 중 패드를 위아래로 밀면 코스가 바뀝니다.
- **진동**: 패스, 슛, 골, 뺏김, GREAT UNION에서 진동합니다(안드로이드). '흔들림·진동' 설정으로 끌 수 있습니다.
- 다른 앱으로 전환하면 자동으로 일시정지되고 소리가 멈춥니다.
- 가로로 긴 휴대폰에서는 조작 버튼을 화면 오른쪽 빈 공간에 두어 골대를 가리지 않습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| **Z** (또는 J) | 동료에게 패스. 패스가 날아가는 중에 누르면 받자마자 원터치 패스 |
| **X** (또는 K) | 짧게 = 빠른 슛, 길게 눌렀다 떼기 = 강한 슛 (차징 중 이동 느려짐) |
| X 차징 중 ↑↓ | 슛 코스 선택 (골대 기준 좌우). X를 누르는 순간 ↑↓를 누르고 있으면 그쪽 구석부터 조준 |
| Esc / P | 일시정지 (계속, 다시 시작, 스테이지 선택, 소리, 화면 흔들림) |
| R | 결과·실패·일시정지 화면에서 즉시 재도전 |
| M | 음소거 켜기/끄기 |
| Enter / Space / Z | 메뉴 결정, Esc 뒤로 |

**모바일**: 왼쪽은 이동 패드, 오른쪽은 패스·슛 버튼입니다. 슛 버튼을 길게 누르면 강슛이고, 오른쪽 위 버튼으로 일시정지합니다. 메뉴는 탭으로 고릅니다.

## 화면에 보이는 안내

- **흰 점선**: 지금 Z를 누르면 공이 갈 길입니다. **빨간 점과 X**는 수비가 가로챌 수 있는 구간입니다(실제 판정과 같은 계산을 씁니다).
- **초록 원**: 동료가 이동하려는 자리입니다. **노란 원과 >>**: 패스한 캐릭터가 침투하는 빈 공간입니다.
- **노란 링이 줄어드는 동안** = 원투 타이밍입니다. 이때 X를 누르면 '원투 피니시' 보너스를 받습니다.
- **빨간 !와 붉은 줄**: 태클 예고입니다. 줄이 진해지면 방향이 고정되니 옆으로 피하세요.
- **골키퍼 옆 흰 흔들림**: 골키퍼가 한쪽으로 쏠린 사전 동작입니다. 반대쪽 구석을 노리세요.

## 캐릭터 (창작 설정)

- **웅심이**: 강한 슛, 안정적인 볼 운반(공격마다 태클을 1회 버팀, 방패 아이콘으로 표시), 수비를 더 멀리서 끌어당깁니다.
- **옹심이**: 빠른 이동, 짧은 슛 준비 시간(강슛 차징 0.36초), 빈 공간 침투를 맡습니다.

## 규칙 요약

- 실수(뺏김, 가로채기, 선방, 아웃, 골대)를 하면 콤보만 끊기고, 짧은 연출 뒤 다음 공격이 시작됩니다. 시간은 계속 흐릅니다.
- 점수는 전진 패스, 라인 돌파, 유인 패스, 드리블 돌파, 골에서 얻습니다. 제자리 패스를 3번 이상 반복하면 0점입니다.
- 콤보 배율은 `1 + 콤보 × 0.5`이고 최대 5배입니다. 최종 점수는 플레이 점수에 남은 시간 × 50을 더한 값입니다.
- 나르샤 응원 게이지가 가득 차면 6초간 **GREAT UNION** 모드가 됩니다(패스 ×1.3, 슛 ×1.15, 주황 잔상, 응원 고조).
- 스테이지마다 별이 3개입니다: 클리어, 최대 콤보 목표, 남은 시간 목표. 조건은 시작 전 소개 화면에 표시됩니다.

## 스테이지

|---|---|---|---|

| 2 | 강릉 — 바닷바람 패스 | 미리 예고되는 횡풍이 긴 패스와 슛을 휘게 함 | 3골 |
| 3 | 알펜시아 — 미끄러운 승부 | 얼음판(공격마다 무작위 구름·물웅덩이 모양)에서만 관성 | 3골 |
| 4 | 춘천 송암 — 주황빛 홈경기 | 압박과 패스 길 차단을 함께 하는 협력 수비 | 4골 |
| 5 | 강릉 하이원아레나 — 미라클 5:4 | 0:4에서 역전, 골마다 수비 배치 변경, 실패 시 −5초, 최후의 수문장 | 5골 |

5스테이지는 2019년 6월 23일 포항전 0:4 → 5:4 역전승에서 영감을 받은 창작 도전입니다. 실제 경기를 재현하지는 않습니다.
요청에 따라 4스테이지는 **춘천 송암**, 5스테이지 결승은 **강릉 하이원아레나**, 3스테이지는 대관령 고원의 **알펜시아**로 설정했습니다. 장소 이름은 `js/data.js`의 `place`에서 바꿀 수 있습니다.

## 스프라이트 교체

1. 서버로 `tools/sprite-sheet.html`을 열고 **내보내기**를 누릅니다. `sprites.png`와 `sprites.json`이 저장됩니다.
2. PNG를 다시 그려 `assets/`에 넣고, `assets/sprites.json`의 `sheet`와 `frames`를 채웁니다.
3. 게임은 같은 이름의 프레임(예: `woong_run0`, `ong_cheer1`)을 PNG로 대체합니다. 이 기능은 로컬 서버로 실행할 때만 동작합니다.
